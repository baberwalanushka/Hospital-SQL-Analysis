# Hospital SQL Analysis

A Hospital Data Analysis project using MySQL to explore patient counts, hospital expenses, departments, cities, and length of stay.

## Tools Used
- MySQL
- SQL

## Analysis Covered
- Total Patients
- Average Doctors per Hospital
- Top Departments by Patients
- Maximum Medical Expenses
- Average Daily Medical Expenses
- Longest Hospital Stay
- City-wise Patient Analysis
- Department-wise Average Stay
- Department with Lowest Patients
- Monthly Medical Expenses
